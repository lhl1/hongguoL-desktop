# HongguoL Desktop

基于 APK 业务与接口重建的独立 Electron 桌面客户端。当前源码版本 **2.3.4**，当前支持的交付目标为 **Windows x64 `win-unpacked`**。

这是独立重建项目，与原应用及其运营方无隶属关系。使用 React/Electron 自己绘制界面，接口请求由本机进程完成；不是官方网站套壳，也不依赖 Android 模拟器界面。

## 功能

- 发现页刷剧、自动播放、首帧呈现与上下滚动回看。
- 搜索联想、动态分页、官方关联的系列剧分组。
- 排行榜、演员作品与动态分类筛选，保留服务端排序和授权状态。
- 筛选自动换行；目录支持卡片和一行一部剧，设置中可修改默认排列。
- 点击剧集先查看简介、系列与选集；可设置直接播放。
- 清晰度选择、默认最高可用、倍速、音量、自动下一集、进度跳转。
- 无边框窗口播放、全屏播放与沉浸状态控制。
- 本地追剧与观看记录、亮暗主题/跟随系统、脱敏诊断日志导出。

账号入口位于设置中，真实账号登录与云记录同步仍有兼容性限制。本地追剧/记录不能当作云同步成功，合同测试不能当作真实登录验证。接口和 SDK 也可能随官方版本变化。

## 获取与构建

```powershell
git clone https://github.com/lhl1/hongguoL-desktop.git
cd hongguoL-desktop
npm ci
npm run build
npm test
```

以上命令检查和编译公开源码，**不会生成可联网播放的完整运行环境**。原 APK 的专有库/SDK 配置和第三方运行二进制没有放入 GitHub，不能通过仅克隆仓库获得它们。

首次运行请按 [Windows 构建说明](docs/BUILD_WINDOWS.md) 自行准备本地运行资源，之后执行：

```powershell
npm start
npm run pack
```

打包输出：`release-2.3.4/win-unpacked/`。复制使用时保留完整目录。默认打包不生成安装器、portable 或 macOS 包。

## 开源范围

MIT 许可证覆盖重建源码与原创矢量标识。**原 APK、反编译的第三方源码、APK 原生库/配置、官方图标、剧集封面/视频、捕获的网络响应、账号/设备资料、调试日志和现有完整发行包不在公开仓库中。**

运行资源需要自行提供，并分别遵循各自的使用和分发条件。参见 [第三方说明](THIRD_PARTY_NOTICES.md)。仓库没有预置他人账户、设备身份或播放密钥，也不会取消官方锁定/授权状态。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `src/` | React 界面、播放器、探索、排行、搜索及设置 |
| `electron/` | 主进程、IPC、APK 请求、媒体与图片代理、偏好、记录和日志 |
| `native-adapter/` | 自行编写的 Java JNI 适配器源码与 Maven 配置 |
| `scripts/` | 本地资源准备、运行检查和部分历史合同测试辅助脚本 |
| `tests/` | 合成合同/回归测试；不包含捕获的原始网络数据 |
| `docs/` | 构建、架构与验证边界 |
| `public/app.svg` | 本项目原创标识，不使用官方图标 |

## 测试与限制

`npm test` 使用合成响应，不需要真实账号或官方网络。没有本地 HEIC 样本/FFmpeg 时，一项图片集成测试明确跳过；历史 Mac 安装合同测试只作用于隔离临时目录，不修改真实系统。

本次开源准备验证：源码构建通过；87 项离线测试中 86 项通过、1 项可选图片测试跳过。构建依赖的已知审计结果见 [安全说明](SECURITY.md#构建依赖审计)。

准备好本地资源后可执行 `npm run test:live`，它使用新建游客上下文访问真实服务，输出脱敏摘要；`npm run test:desktop` 使用隐藏且静音的 Electron 测试窗口。在线测试会真实请求服务，应在需要时主动执行。

CI 只做源码构建与离线合同测试，不携带专有运行资源，不发送短信，不声称验证真实播放或云同步。
