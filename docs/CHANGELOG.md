## 2.3.8 — 同一媒体时间线的无感连播

Windows 工作版完成于 2026-10-25；本次公开源码同步日期为 **2026-11-12（UTC+8）**。默认构建目标仍仅为 Windows x64 `win-unpacked`。

### 观看时的变化

- 当前集播完后，下一集提前追加到同一个播放器；自然连播保持视频源和媒体时钟连续，不经过两个播放器重新启动的交接。
- 音频使用 FLAC 48kHz 双声道，避免每集独立 AAC 编码的预滚间隙。视频与音频边界按实际采样对齐。
- 集数、本集进度和观看记录正常更新；自然换集不翻动、不主动浮出控制栏。
- 关闭自动下一集后停在当前集结尾；随后点击重播仍播放当前集。手动选集、上一集／下一集、拖进度和清晰度切换保留。
- 下一集是否能接入仍遵守原目录及锁定状态，不跳过授权。源片本身的静音和网络数据迟到仍可能造成等待。

### 怎样复测

| 命令 | 内容 | 资源与联网 |
| --- | --- | --- |
| `npm run build` | TypeScript 和 Vite 编译 | 仅 npm 依赖 |
| `npm test` | 合成响应、状态和边界测试 | 不访问真实服务；可选本地集成按资源跳过 |
| `npm run test:audio` | 实际 AudioWorklet PCM 接点检查 | 自行提供 FFmpeg；不访问剧集服务，隐藏静音 |
| `npm run test:gapless` | 三次连续真实剧集接续、暂停／重播／手动切集 | 完整本地运行资源；访问真实服务，隐藏静音 |

音频脚本使用固定种子的非周期噪声，三段长度精确到单采样，第二段改变分辨率和帧率。比较接点两侧与参考音频的采样偏移，检查有无额外插入、丢失或静音断段。测试输出只保留合成内容的数值摘要，不导出真实剧集音频。

## 2.3.7 — 连播方式与无边框窗口拖动

- 设置新增默认连播方式，默认“无感连播”，可切回原来的翻动效果。
- 无边框窗口顶部和左右两侧扩大可拖动范围，中央点击区、返回、底部控件和抽屉不被拖动区挡住。
- 提前准备下一集并保持旧末帧；未就绪或用户暂停时按对应状态等待。
- 这版采用两个播放器交接，实测约 100–118ms；音频仍可能卡断，其机制已由 2.3.8 替换。

## 2.3.6 — 上一集与积极缓冲

- 增加上一集按钮。
- 默认积极缓冲，可在设置中关闭并保存；队列和并发有上限，优先保障当前集。
- 监测播放时钟的实际进展，处理没有 waiting 事件的持续停滞；恢复次数受限制。
- 用户主动暂停后保持暂停，不因后台缓冲完成而强行继续。

## 2.3.5 — 暂停较久后的播放恢复

- 取消、重复打开或释放媒体能力时，终止关联旧解码任务，避免任务占满。
- 暂停较久时释放旧连接并保留已显示画面；继续时重新获取，从当前集原进度播放。
- 忽略旧视频的错误事件和迟到跳转，避免覆盖最新选集。
- 失败可有限次自动恢复，仍保留手动重试。
